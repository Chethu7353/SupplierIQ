# SupplierIQ

AI-Powered Supply-Chain Crisis Simulation & Decision Intelligence Platform.

## Overview

SupplierIQ is a decision-support platform designed to help businesses
understand supplier risks, simulate supply-chain disruptions, and
compare possible response strategies.

The platform will use data-driven calculations and AI-assisted
explanations to help users evaluate decisions.

## Problem Statement

Supply-chain disruptions such as supplier delays, price increases,
capacity reductions, and inventory shortages can affect business
operations.

SupplierIQ aims to provide a structured environment to analyze these
risks and evaluate alternative responses before making decisions.

## Objectives

- Manage supplier and inventory information.
- Import and validate supplier data using CSV files.
- Calculate supplier risk indicators.
- Analyze inventory coverage and potential shortages.
- Simulate supply-chain disruptions.
- Compare alternative response strategies.
- Provide evidence-based explanations using an AI agent.
- Maintain decision history and audit records.
